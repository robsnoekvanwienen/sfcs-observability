Semantic Field Coherence Score (SFCS)

SFCS is an observability metric designed to measure semantic field coherence across AI outputs.

Main Result

Across finance, AI, medical, and legal domains, SFCS exhibited consistent degradation patterns under progressive semantic drift.

Key Insight

SFCS appears sensitive to semantic field coherence rather than truth, factual correctness, or logical agreement.
